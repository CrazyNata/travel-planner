RRamingo

Онбординг: сначала ценность, потом подсказки

Три коротких экрана на первом запуске и две контекстные подсказки внутри настоящего интерфейса Ramingo. Это визуальные шаблоны для согласования, не Android-реализация.

До одобрения: Kotlin/Compose, Supabase, существующие поездки и основные пользовательские потоки не изменяются. Визуал использует текущие Manrope, палитру, карточки, радиусы и паттерны Ramingo.
Режим предпросмотра: Язык:
1 · Welcome Три экрана Plan → Build → Start
2 · Choice Действие пользователя Создать поездку или осмотреться
3 · Context Одна подсказка за раз Только в момент первого действия
4 · Return Повторный просмотр Из Settings, без сброса данных

Версия приложения
0.2.39
Повторный просмотр возвращает в приложение после последнего экрана. Пользовательские данные, onboardingCompleted и флаги подсказок остаются без изменений.
Вход: Settings → Показать обучение. Это не делает пользователя новым.
Действие предпросмотра: выберите Next, Skip или CTA внутри первого телефона.

Что именно предлагается согласовать

Шаблон оставляет основной интерфейс Ramingo прежним: добавляются только три welcome-экрана, две ненавязчивые подсказки и точка повторного входа из Settings.

СостоянияonboardingCompleted, createTripHintSeen и addPlaceHintSeen. Системные настройки и данные поездок не затрагиваются.Новая библиотека для boolean-флагов не нужна.
КонтекстПодсказка появляется только после выполненного предыдущего действия: Home → создание поездки → первая поездка → добавление места.Не больше одной подсказки одновременно.
