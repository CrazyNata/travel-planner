CI: [GitHub Actions run](https://github.com/CrazyNata/travel-planner/actions/runs/35434867706)

## Не закрыто этим прогоном

- реальный Sign in with Apple и Google OAuth;
- письмо восстановления пароля и возврат по native deep link;
- фактическое сохранение/редактирование/удаление данных с повторной загрузкой;
- реальная загрузка фото через PhotosPicker в Supabase Storage;
- нажатие системного уведомления с переходом в конкретную поездку;
- системные разрешения геолокации и Photos на физическом iPhone;
- удаление аккаунта с подтверждением и проверкой Edge Function намеренно не выполнялось;
- подписанный Release archive, TestFlight и App Store Connect;
- QA на физическом iPhone.

Проверка была read-only для существующей поездки. Черновик новой поездки был отменён; существующие пользовательские данные не удалялись и не перезаписывались.

Временные GitHub Actions secrets `IOS_QA_EMAIL` и `IOS_QA_PASSWORD` удалены после проверки.

Android и Web в ходе этой проверки не изменялись.
