# Production readiness — сверка с feedback

Дата сверки: 2026-09-12.

## Уже есть в приложении

- Первый запуск пользователя без поездок ведёт в три экрана обучения, затем — прямо в создание первой поездки.
- Обучение можно открыть повторно из профиля.
- Погода Android учитывает города поездки, сохранённые общей web-версией.
- В профиле есть системная тема, отправка отзыва и переход к оценке приложения.
- Данные поездок и состояние обучения сохраняются через существующий Supabase `user_data`; схема базы не менялась.

## Что закрыто только частично или ещё требует внешнего шага

- **ASO:** подготовлен текст карточки в [`google-play-aso-draft.md`](google-play-aso-draft.md), но текст и скриншоты ещё нужно сохранить и проверить в Play Console.
- **Production Access:** подготовлен честный черновик в [`production-access-questionnaire-draft.md`](production-access-questionnaire-draft.md). Нужны фактические данные закрытого теста; шаблонный PDF нельзя отправлять без проверки.
- **Crash/performance monitoring:** отдельный SDK мониторинга в приложение не добавлялся. После закрытого теста нужно проверить встроенные Android Vitals в Play Console; подключение внешнего сервиса требует отдельного выбора провайдера и проверки privacy/data safety.
- **Accessibility:** базовые content descriptions есть, но полноценный аудит TalkBack, крупного шрифта, контраста и всех touch targets ещё не проведён. В этом изменении семантика добавляется для ключевых собственных переключателей/строк; ручная проверка на устройстве остаётся обязательной.
- **Regular updates:** это процесс релизов, а не функция приложения; нужен календарь обновлений после первого production-релиза.
- **Marketing/visibility:** это не реализуется кодом и требует отдельного плана каналов/бюджета.

## Текущий релизный статус

Подписанный Android `0.2.60` / `10069` собран и загружен в закрытый тест. По последней проверке Play Console изменения находятся на проверке; production ещё не опубликован.
