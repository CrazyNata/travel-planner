# Правило расчета маршрута в Ramingo

Для каждого сохраненного переезда Ramingo считает расстояние по реальной сети дорог или пешеходных дорожек:

1. Из ссылки Google Maps берутся начало, конец, промежуточные точки и `travelmode`.
2. Все точки передаются маршрутизатору в сохраненном порядке. Для автомобиля используется `driving`, для пешего маршрута — `walking`, для велосипеда — `cycling`.
3. Основной расчет выполняется через дорожный маршрутизатор. Веб-версия и Android используют одинаковую последовательность провайдеров: проксированный через Ramingo Valhalla OpenStreetMap, затем Mapbox, затем резервный OSM-маршрутизатор.
4. В итог поездки попадают только полностью рассчитанные по сети маршруты. Расстояние по прямой не смешивается с дорожным расчетом и не показывается как итоговое количество километров.
5. Если координата начала или конца в ссылке явно не соответствует городу переезда, используется координата города, но промежуточные точки маршрута сохраняются.

Это правило применяется к общему расстоянию поездки во всех экранах маршрута и не зависит от конкретной поездки.
